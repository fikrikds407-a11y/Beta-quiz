# FIKK SMART QUIZ

**Learn More. Play Smarter. Know Better.**

Aplikasi kuis interaktif lengkap dengan:
- 5 Rumpun Mata Pelajaran & Tambah Mata Pelajaran Khusus
- AI Quiz Generator & Import Documents
- Study Mode & Exam Mode (Timer)
- Pembahasan Lengkap, Bookmark & Remedial Soal Salah
- Focus Music & Audio Studio (Web Audio Synthesizer + Impor Musik Lokal)
- 8 Pilihan Tema Warna + Dark Mode / AMOLED

## Cara Menjalankan
1. Ekstrak file ZIP ini.
2. Buka terminal di dalam folder `fikk-smart-quiz`.
3. Jalankan perintah:
   ```bash
   npm install
   npm run dev
   ```
4. Buka tautan localhost yang muncul di browser.
